# neKerek — студия веб-разработки

Одностраничный сайт на HTML/CSS/vanilla JavaScript. Откройте `index.html` в браузере.

## Настройка
В `js/main.js` замените пустые значения `CONFIG.whatsapp`, `CONFIG.telegram`, `CONFIG.email` на настоящие контакты. До настройки формы заявка не отправляется: пользователь может скопировать подготовленный текст.

## Портфолио
Кнопка AutoFlow KZ ведёт на https://autoflow-kz.vercel.app/. Проект помечен как демонстрационный.

## Изображения
Используются внешние фотографии Unsplash по URL в `css/styles.css`; для надёжной production-публикации замените их на лицензированные локальные WebP/AVIF. Визуальные фото и иллюстративный UI — приближение к референсу, не точная копия.

## Публикация
Создайте GitHub-репозиторий с этими файлами и импортируйте в Vercel. Framework Preset: Other, Root Directory: ./, build command не требуется.

## Проверка
Протестируйте сайт на ширинах 390px, 768px, 1440px; проверьте загрузку внешних фотографий и ссылки. Пиксельное совпадение с макетом не проверено автоматизированным браузерным сравнением.

## Исправления интерфейса
Исправлены адаптивная верстка, мобильная навигация и форма. Добавлены выбор канала, подстановка услуги и копирование заявки. Перед приёмом заявок заполните CONFIG реальными контактами.
